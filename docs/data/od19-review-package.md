# OD-19 Reviewer Package

**246 provisions await qualified review.** This package does not attempt to resolve
them. It assembles what a reviewer needs in order to, and orders the work so the
provisions that could change a decision are seen first.

Artefacts: `data/review/od19_review_package.jsonl` (one row per provision, ranked)
and `data/review/od19_summary.json`. Generated by
`scripts/build_review_package.py`.

---

## What OD-19 is, precisely

Span verification proves every transcribed criterion is **faithful** to the
regulation. Nothing establishes that the right criteria were *chosen*, or that none
was missed — and a non-clinician chose them.

Phase 3 gave the question a denominator: 356 provisions enumerated, 312 substantive,
30 carrying the 35 criteria, 80 ruled `NON_DECISION_RELEVANT` with recorded reasons,
**246 awaiting review**. Seven concrete gaps were confirmed by inspection. One of
them — the 410.32 mammography exception — was closed in Phase 4, which is why the
figure is 246 rather than 247.

Engineering has taken this as far as it can. What remains needs someone qualified to
read coverage regulation.

## What each row carries

| field | |
|---|---|
| `policy_id`, `policy_version` | which regulation and revision |
| `section_path`, `paragraph_path`, `hierarchy_level` | where it sits |
| `authoritative_text` | **the provision itself** — no lookup required |
| `source_page` | for citation |
| `current_classification` | always `REQUIRES_HUMAN_REVIEW` |
| `obligation_markers` | which obligation words appear |
| `cited_by_criteria` | criteria that explicitly cite this paragraph |
| `same_section_criteria` | criteria transcribed from the same section |
| `suggested_requirement_type` | **a suggestion from a word scan, labelled as one** |
| `review_question` | the specific question this provision poses |
| `permitted_decisions` | the five allowed outcomes |
| `reviewer_decision`, `reviewer_rationale`, `reviewer_id`, `reviewed_at` | **empty** |

## Nothing is pre-filled

`reviewer_decision` is `null` in all 246 rows, and a test asserts it stays that way.

A pre-filled decision would let a lexical suggestion become a recorded human
judgement the moment someone accepted the defaults — which is exactly how an
unreviewed criterion set would come to look reviewed. The suggested requirement type
is offered because an empty form is harder to work than one with a starting point,
and it carries `SUGGESTION ONLY` in its own `suggestion_basis` field.

## The five permitted outcomes

| decision | means |
|---|---|
| `REPRESENT_AS_CRITERION` | a condition a case can satisfy or fail; transcribe it |
| `NON_DECISION_RELEVANT` | structural or definitional; bears on no decision |
| `MERGE_WITH_EXISTING_CRITERION` | already covered by a transcribed criterion |
| `REQUIRES_POLICY_INTERPRETATION` | meaning is genuinely unsettled; needs a policy ruling |
| `REQUIRES_CLINICAL_REVIEW` | needs clinical rather than regulatory judgement |

The last two exist so a reviewer can record *"I cannot settle this"* without either
guessing or leaving the row blank. A form that only permits confident answers
manufactures confident answers.

## Priority ordering

| priority | reason | n |
|---|---|---|
| 1 | cited by an existing criterion | **5** |
| 2 | alters applicability | 8 |
| 3 | contains an exception | 10 |
| 4 | contains an exclusion | 5 |
| 5 | affects timing | 11 |
| 6 | affects eligibility | 10 |
| 7 | affects documentation | 33 |
| 8 | affects medical necessity | 7 |
| 9 | affects code applicability | 7 |
| 10 | elaborates a transcribed section | 48 |
| 11 | remaining | 102 |

**Priority 1 is the urgent tier**: a criterion already in use may not be evaluable
without these. It contains 42 CFR 410.32 `(b)(3)` — the supervision levels that
criterion C03 invokes but does not contain (**R-51**) — and 410.38 `(d)(1)(ii)(A)`
and `(B)`, the prior-to-delivery timing conditions that C02 and C03 plausibly depend
on.

These five are recorded as **known dependencies**, established by individual
inspection in Phase 3, not by pattern match. The dependency is semantic: C03 says
"the appropriate level of supervision" and never writes the words "paragraph
(b)(3)", so no citation regex can find it.

An earlier version of this ranking counted "shares a section with a criterion" as a
citation. That put **65** provisions in priority 1 on a relationship most of them
did not have, each carrying a review question asserting a dependency that was not
there. A form that tells a reviewer something false is worse than one that tells
them nothing. Those provisions now rank 10, under a question that describes the
relationship accurately.

## Ranking does not reduce the denominator

All 246 provisions require review. Priority decides only which are seen first. A
provision ranked 11 is **not** established as unimportant — it is one no lexical
signal flagged, by a scan that cannot read meaning. Asserted by test against the
summary's own note.

## What completing this would and would not settle

**Would settle:** whether the criterion set is complete for these five policies at
these revisions. That closes OD-19, unblocks `completeness_verified`, and lets the
gold-set audit move off `REQUIRES_REVIEW`.

**Would not settle:** whether the criteria are *clinically* correct (a separate
question, and `clinically_validated: false` stays until a clinician says otherwise);
whether the decision logic for each policy is right (OD-23/OD-24 — a reviewer would
likely surface more of that, but declaring logic is its own step); or anything about
NCDs and LCDs, which are not in the corpus (R-55, OD-21).
