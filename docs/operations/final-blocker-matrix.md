## The one thing that moved this phase

Portability was the last locally actionable item, and it was fixable at the seam the
design already had: `source_uri` is provenance for a human, nothing consumes it, and the
canonical identity is `source_url` — a public URL that was never affected. So the fix is
serialization-level, the data model is unchanged, and no clinical or evaluation content
was touched.

Everything else on this page is somebody else's decision, and each has an owner *category*,
a required action and closing evidence in
`docs/operations/external-dependency-register.md`.
